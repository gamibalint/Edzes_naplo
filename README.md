# Edzésnapló
Ezt a weboldalt a kedvenc hobbim hatására készítettem.
A weboldal segít rögzíteni és számon tartani az edzéseinket illetve gyakorlatainkat

### Szükségletek
- Java 21
- Node.js

### Backend indítása
- Nyiss meg egy terminált a backend mappában
- .\mvnw spring-boot:run

### Frontend indítása
- Nyiss egy terminált a frontend mappában
- npm run dev
- Böngészőben http://localhost:5173

### Beállítások
- Adatbázis: a backend/src/main/resources/application.properties fájlban.
- A backend címe: a frontend/.env fájlban.
